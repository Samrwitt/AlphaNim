AlphaZero on 10-stone Nim

Play against the trained agent or watch its 300 training games

Run training with python3 nim.py. Build the static page without retraining with python3 build_site.py. Verify with python3 -m unittest -v test_nim and node test_web.cjs.

What learns?

Starting from random weights, a shared network predicts two action probabilities and a signed outcome. Monte Carlo tree search uses those predictions to explore legal moves. Search visit fractions form the policy target; the winner of the completed game supplies the value target. Ten batches of 30 self-play games generate exactly 300 games. After each batch, our own backpropagation and gradient descent improve the network.

The loss is −π·log(p) + (v−z)² + c∑w². No model.fit(), premade network, automatic differentiation or optimizer is used. Array operations come from NumPy. The terminal winner is the player who takes the last stone; values change sign each time search crosses to the opponent's turn.

The page embeds the learned weights. JavaScript runs the same forward pass and 64-simulation search, so human-vs-AlphaZero works on static hosting without a Python server. Human games never change the 300 training games. Recorded training replays include exploration and earlier model versions; live play uses the final model without exploration noise.

The architecture is deliberately small: ten one-hot inputs, 24 tanh hidden neurons, two policy logits and one tanh value. We adapt AlphaZero's network size and optimization to this tiny game. Exact solving is used only to check the final choices at all ten positions, not to guide gameplay or training. Reference: the AlphaZero paper.
